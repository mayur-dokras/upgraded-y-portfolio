# Yukta Soman | Project Management Portfolio

Live site: https://mayur-dokras.github.io/upgraded-y-portfolio/

A static portfolio site (no build step). Open `index.html` locally, or serve it with GitHub Pages from the `main` branch root.

- `index.html`: page content
- `assets/css/style.css`: styles
- `assets/js/main.js`: 3D hero, experience Gantt data, skills matrix
- `assets/img/`: images
- PDFs: CV and evidence portfolio downloads

To update experience or skills, edit the `roles` and `matrix` arrays in `assets/js/main.js`.
